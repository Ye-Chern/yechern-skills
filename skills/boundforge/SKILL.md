# BoundForge · 双循环数学研究

围绕数学问题探索，用记录支持恢复与下一步判断。内循环在一个研究片段（episode）内继续、换方法或转向；外循环比较多个方向的积累。每轮选择能推进问题的具体行动，保留有用结果、障碍和新想法。

## 开始研究

写清问题、假设和可行域。当前工具处理下确界 `A = inf_{x∈F} f(x)`：下界为 `L ≤ A`；可行见证或有效极限构造给出 `A ≤ U`。最优值与是否达到分别研究。研究上确界时先明确转化为下确界的对应关系。

配套程序、示例和引用都在本 skill 目录，需要 Python 3.10+，只用标准库。从这个目录运行 `python examples/quickstart.py` 可体验一个完整的小例子；它默认使用临时目录。正式任务把数据库与论证文件放进任务目录，命令均显式指定同一 `--db` 路径。命令选项见 `python -m boundforge --help`，需要操作示例时读 [账本说明](references/ledger.md)。

初始化问题与 `inner_effort`、`outer_effort`（0—100），添加方向并开始 episode。这两个值表达探索偏好；用用户的设置，未指定时可从 50/50 起步。具体工作时长、路线与操作次数随问题和已有资源约定安排。

## 探索与核查

选择推导、构造、计算、文献、反例或论证检查中当前最有用的一项。观察、障碍、方法和负面结果用 `observation`、`obstruction`、`method`、`negative` 保存，可省略附件。界和引理附论证材料；实际自查后记 `self_check`，计算记 `reproducible_computation`，其他审查按实际方式记录。账本端点使用普通浮点数，精确端点、假设和论证范围保存在论证文件中；记录值相同不足以判断精确相等。

用 `work-start`、`work-end` 记录实际研究片段，供内外循环比较。记录研究发现与数学界两个层面：探索和计算能指导下一步，更新界的论证须已完成相应核查。候选最优值用 `conjecture`、`evidence` 保存，需要比较时看 `candidates`；模型表是可选扩展。

有意义的节点用 `decide` 参考当前 episode 与其他方向的积累，再结合数学价值、证明难点和具体新想法作决定。软指标接近时视作大致相当，无需为了小分差改路线。速率受记录粒度影响，按有用发现记录，不为提高分数拆分同一发现。换方法或角色可留在当前 episode；换方向时结束它，再开一个。需要理解估计时读 [决策模型](references/decision_model.md)，希望改变研究视角时读 [角色与方法](references/roles.md)。

## 恢复与交付

用 `state` 取回方向、论证、依赖和未完成工作，结合原材料确定下一步。临时暂停时结束 work，并在现有任务入口留下下一动作。任务完成或明确放弃时关闭 work 和 episode，再 `finalize`。

交付数学结果、实际核查方式、未决问题及可继续的入口。账本数值一致时，仍从原论证确认精确结论和达到性。记录应帮助研究与恢复，详略服从任务。

遇到界矛盾、失效依赖、搬迁或中断时查 [HELP](HELP.md) 的对应小节。项目通用说明集中在 [NOTICE](NOTICE.md)，正常工作无需加载或复述。
