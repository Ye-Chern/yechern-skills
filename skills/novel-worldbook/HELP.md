# 少见情形

## 前置技能不可用

若找不到 progressive-reading 或 durable-task，查看已安装技能列表和本地路径。可以先检查原文、现有世界书和可用格式；明确缺少的阅读或恢复能力，待技能可用后再继续全文流程，不要声称已完成完整阅读。

## 范围或剧透要求不清

先用简短问题确认会改变成品的选择，例如是否包含结局、作者感言或附录，以及目标读者。确认前可继续做不依赖这些选择的原文和现有材料检查。若只有部分原文可用，标出缺失部分与当前覆盖状态。

## 目标格式特殊

角色卡或平台导入格式需要目标平台的字段说明、样例或现有可用文件；按其结构映射条目，并把触发词、权重等字段作为格式设置，不写成小说设定。目标平台不明且会影响导入时，先保留 Markdown 稿并询问必要信息。

用户要求阅读网站或自包含 HTML 时，先整理内容，再按查阅用途添加导航、搜索或详情。若承诺限制剧透，检查名称、别名、搜索结果、摘要和关系链接是否暴露后文；只描述实际检查过的范围。运行专用工具时遵循对应技能。

## “首次出现”与复杂时间线

普通条目给出可靠出处即可。只有需要断言某名称或事件“首次出现”时，才回查前文与相关别名。倒叙、时间流速或不同披露顺序影响理解时，分别说明事件发生、读者获知和角色得知的先后；不确定年份可用相对顺序。

## 阶段交付

正文尚未读完时可交付阶段世界书，但须同时给出未读范围和续读断点。阅读完成与整理完成分开记录；不完整的导入、运行或视觉检查按实际验证状态说明。
