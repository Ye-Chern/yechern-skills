# 小说世界书

将小说整理成便于查阅的世界书。正文读全，内容按重要性取舍；条目忠于作品，保留有用的原文位置。

## 前置 skill

先读取并使用 **progressive-reading** 与 **durable-task**。前者负责实际阅读、理解修订与回读，后者负责状态保存和恢复，本 skill 负责整理与交付。

在可用技能中按名称查找。使用本仓库时，入口分别是 [`../progressive-reading/SKILL.md`](../progressive-reading/SKILL.md) 与 [`../durable-task/SKILL.md`](../durable-task/SKILL.md)。已安装到别处时采用当地路径；前置缺失就说明缺什么，不声称已经加载。可以保留独立完成的材料检查，待前置可读后再按完整流程推进。

## 确定产物

确认小说版本、正文可访问范围、受众、剧透方式与交付形式。用户只说“世界书”时，默认整理一份带目录和条目互引的 Markdown 文档；已有模板、网站或导入格式要求则沿用。用户授权整本世界书时，可阅读全部正文；展示给读者的剧透范围另行处理。

范围不清时先用简短说明确定取舍。保留用户已提出的内容要求。未指定规模时，以主要人物、世界关系、核心规则和主线因果足够清楚为准，篇幅随作品调整。

## 读完并整理

1. **复用恢复入口。** 在同一状态中注明阅读范围、整理草稿、当前取舍与下一步。已有项目先核实原文、覆盖记录与现行产物，接着未完成处做。
2. **按阅读 skill 覆盖全文。** 阅读时将有用的事实和定位写入简记或草稿，后文改变理解时同步修改。可以边读边整理，尚有未读正文时保留“阶段草稿”标记。
3. **围绕作品组织内容。** 常见部分包括整体导览、人物与关系、地点和世界、组织与族群、力量或运行规则、主要事件及时间线。按作品合并或删减空项；某项缺乏原文依据就留空或说明未交代。整理要能说明主要人物如何变化、规则如何起作用、关键事件怎样导致后果。
4. **全文读完后收拢条目。** 合并别名与重复内容，补上后半部的重要变化与结局，修正被后文推翻的说法。把仍影响全书理解的矛盾定向回读，保留原作的歧义。
5. **检查并交付。** 核对正文无未读缺口，检查世界书的核心内容与所需格式，交付文件和可续做入口。阅读完成与世界书整理完成分别说明。

减少边缘条目、引文数量、主题解读与界面加工，可以节省整理成本；用户要求的全文阅读继续完成。时长或工具限制导致未读完时，先保存断点并交付阶段成果，保留原目标。

## 条目依据

- 重要事实留可回查的章节或正文位置。一条短说明加一两个有效锚点通常足够；定位不清或影响全局的地方再补查。
- 原文明确陈述、角色的说法与自己的归纳分清。角色推测和不可靠叙述保留出处与适用视角；一句话在原文出现，不足以证明它表达的规则为真。
- 别名合并须有依据，同名人物注意区分。规则注明生效阶段、限制或例外；能力、身份与关系随故事变化时保留变化过程。
- 事件时间、披露位置和角色得知时间在影响理解处分别说明。不确定年份可用先后关系，未知动机或缺失设定保留未说明。
- 直接引文回原文核对，归纳使用转述。世界书中的名字、规则与事件来自作品；为便于分类自拟的栏目或概括标明为整理用语。
- 旧世界书、网页、模型记忆与用户给的参考页可帮助查找或组织，事实回到本次原文核实。阅读过程中的猜测只在有查阅价值时进入成品。

需要选择条目结构或特殊输出时，读 [内容与形式](references/content-and-formats.md)。

## 交付检查

全文覆盖按 progressive-reading 的记录核对；分段脚本、笔记数量和“已完成”标题都不能替代实际阅读。已有可信覆盖可以沿用，缺口定向补读。

内容检查集中在主线因果、主要人物结局、世界关系、核心规则和后文反转；需要时回原文。检查有效定位、互引和仍在使用的旧说法。原作本身的矛盾可列为未决，不为完整表格补写设定。

用户指定可运行或可导入的产物时，再做对应的打开、交互或导入检查；没有实际验证的部分如实说明。普通文档检查可读性、定位与链接即可。
