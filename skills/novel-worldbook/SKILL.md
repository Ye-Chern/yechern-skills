# 小说世界书

把小说整理成便于查阅的世界书。阅读覆盖须达到全文，条目按用户用途和作品重要性取舍，并保留可回查的原文位置。阅读和交付的共通边界见 [NOTICE](NOTICE.md)；少见情况见 [HELP](HELP.md)。

## 前置技能

先使用 [progressive-reading](../progressive-reading/SKILL.md) 处理实际阅读、整体理解修订与回读，同时使用 [durable-task](../durable-task/SKILL.md) 管理跨上下文状态。根据本机已安装的技能路径调整引用；找不到前置技能时，查看 [HELP](HELP.md)。

## 确定交付

确认小说版本、正文范围、受众、剧透方式和交付形式。用户只说“世界书”时，默认交付带目录和条目互引的 Markdown 文档；已有模板、网站或导入格式时沿用。用户要求整本世界书时，仍需遵循其允许的剧透范围。

未指定规模时，围绕主要人物、世界关系、核心规则和主线因果组织内容，篇幅随作品调整。常用条目结构与交付形式见[内容与交付形式](references/content-and-formats.md)。

## 阅读并整理

1. **接续项目。** 在同一恢复入口记录阅读范围、整理草稿、当前取舍和下一步。已有项目先核对原文、实际覆盖和现有产物，再从未完成处继续。
2. **沿阅读循环覆盖正文。** 按 progressive-reading 的稀疏预读、预测、波次精读和触发式反刍推进。将有用事实与位置写入简记或草稿；后文改变理解时同步修订。可以边读边整理，未读完时标为阶段草稿。
3. **按作品安排条目。** 常用部分包括整体导览、人物与关系、地点与世界、组织与族群、力量或运行规则、主要事件与时间线。合并不适用的栏目；缺乏依据时说明未交代。需要让读者看清主要人物如何变化、规则如何起作用、关键事件如何造成后果。
4. **读完后校订。** 合并重复条目和有依据的别名，补入后半部重要变化与结局，修正被后文推翻的说法。仍影响全书理解的矛盾，回到相关原文核查并保留作品的歧义。
5. **核对并交付。** 对照全文覆盖记录，检查主线因果、主要人物结局、世界关系、核心规则、后文反转、出处和互引。交付世界书与可续做入口，分别说明阅读是否完成、整理是否完成。

整理成本可通过删减边缘条目、引文、主题解读和界面加工来控制；这不改变全文阅读目标。遇到时长或工具限制时，保存准确断点并交付阶段成果，继续保留未读范围。

## 条目依据

世界书以本次原文为依据；旧世界书、网页和其他参考材料用于定位或组织。区分明确叙述、角色说法、自己的归纳与未知，不可靠叙述保留视角。重要条目给出可回查的位置，直接引文回原文核对；作品未说明的内容保留未知。

合并别名须有依据，同名人物注意区分。能力、身份、关系和规则的阶段、限制与变化在影响理解处说明；事件发生、文本披露和角色得知的先后同样按需要区分。自拟分类属于整理用语，不当作作品设定。正文全文阅读与条目收录深度分别处理。
