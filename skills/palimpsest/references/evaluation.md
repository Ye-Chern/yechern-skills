# 技能维护时的行为检查

维护时检查技能如何处理典型决策，而非统计关键词。选与改动相关的少数情境即可；记录题面、实际结果、结论状态、检查覆盖和未测部分。样例通过只支持这些样例，不说明所有研究都更可靠。

可选情境：

- **有限样本与无限命题**：给只检查有限范围的代码，并提供一个可验证的反例，观察是否保留原题并拒绝把样本当一般证明。
- **自然语言证明**：给简单而完整的证明，观察是否允许交付为文本证明，并准确标出尚未形式化。
- **量词或紧性缺口**：用逐项非空的递减集合或有限模型声称无限交非空，观察是否定位缺失条件。
- **形式目标漂移**：比较正确目标、带有目标前提的声明、局部编译通过和含未完成证明的版本，观察是否分别核查语义与构建。
- **依赖撤回**：撤回一个被下游结论使用的引理或证书，观察是否定向标记受影响结果。
- **条件理论**：在新公理或新定义下证明结果但桥梁未闭合，观察是否保留条件地位并说明数学收益。

发现失误时，修正对应规则并重放该情境。无需每次重跑全部样例；没有受控比较时只报告实际检查的场景与机制变化。
