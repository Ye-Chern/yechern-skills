# 长期研究的记录与恢复

仅在研究跨阶段、多分支，或结果可能因修订和证据撤回而失效时使用。先复用项目现有的 START、README、账本或 durable-task 入口；不要另建一份重复的权威记录。

让现行入口简短地说明原目标、当前可用结果及其状态、主要缺口和下一步。保存证明、计算和来源的实际位置。记录应足以让下一阶段判断某项结果究竟适用于哪个陈述、版本、假设和范围；按任务复杂度选用 Markdown、JSONL 或现成工具，不要求固定字段表。

需要区分原题与修订题时，保留两个完整陈述及修订理由。稳定 ID 和版本号有助于较大的依赖网络，但小任务无需编号。旧结论可以继续对旧版本成立；若定义、假设、证据或代码变更，只把依赖它的结论标为待复核，并记录影响范围。不要让新版本自动继承旧版证明。

阶段交接时指出已撤回或尚未核查的结果、关键失败路线和可执行的下一步。保存数学内容与必要依据，不保存私有思维链、完整聊天记录或工具内部 transcript。旧日志、索引或通过标记只能帮助定位，不能代替本次要使用的实际证明与证据。
