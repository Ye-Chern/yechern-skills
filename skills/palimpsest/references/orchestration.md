# 按障碍分工

只有当工作可以独立验收、且能推进当前障碍时才委派。主 agent 保留原题、主稿和结论整合责任。不同模型、角色或相互赞同本身不能证明独立正确。

适合委派的工作包括：提出一条实质不同的路线；证明指定引理；从原题寻找并验证反例；核对文献定理的假设；审查候选证明中最薄弱的一步；或把固定陈述完整形式化。不要为了角色齐全拆分一段连续推理。

给任务提供完成它所需的题面、定义和来源。说明精确义务、允许使用的前提以及要返回的证明、反例或证据。需要隔离文件写入时，指定分支目录和文件所有者。其余交付细节按情形补充，不必填写固定模板。

接收结果时，确认它针对正确的命题版本、没有暗加假设，并且证据覆盖其声称的结论。若有分歧，围绕最小的未决推理继续查证。重新委派要有具体新问题或证据；空泛重复检查不推进结论。

调用当前环境支持的原生协作工具，并遵守其并发限制。工具不可用时由主 agent 串行推进。子代理通常不再递归派活；若进一步拆分确有收益，由负责人按实际容量决定。
