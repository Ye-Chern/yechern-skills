# 少见情形与恢复

## 初读体验与剧透

若用户要求避免提前获知后文，不做跨全文预读；仅在获准范围内抽样，完成当前范围后再扩展。若要求完全无剧透，先确认可见范围，并避免目录、搜索结果、外部摘要暴露后文。

## 原文不完整或索引不稳

转换 PDF、EPUB 等格式时检查正文顺序、首尾和明显缺页；转换失败或无法访问的部分列为缺口。重号章节、倒叙或标题缺失时，以原文文件顺序和字符位置定位。原稿转码或换行变化后重新核对偏移。

## 读取被截断

若输出提示截断、省略或中间缺失，只登记能够确认看到的部分。缩小读取范围，从最后确认的位置续读；边界不清时少量重叠。部分段全部读完后才能标为已通读。无法确认旧覆盖时，从最近可靠断点补读。

## 反刍条件

不必每波都回读。只有新揭示、矛盾、态度变化、意象重现或当前问题使旧场景值得重看时，才回到原文及邻近上下文。取不到原文就保留待回读项；只看旧摘要时注明尚未回读。

## 分段脚本

脚本只接受 UTF-8 `.txt`、`.md`、`.markdown`，输出目录必须为空，默认会生成跨全文的标题与开头节选。保留初读体验时用 `--no-scout`。偏移是原文解码后的 Python Unicode 字符下标，区间左闭右开；不是 UTF-8 字节数或 UTF-16 下标。分段只能辅助定位，进度仍以实际读过的范围为准。完整接口见 [阅读细则](references/protocol.md)。
