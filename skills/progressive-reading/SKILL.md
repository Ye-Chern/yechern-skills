# 渐进式阅读：稀疏预读 → 预测 → 波次精读 → 反刍

先形成可撤销的整体印象，再随阅读检验和修订。用原文中的反例、新揭示与细节改变理解，直到正文全部读完。记录保持简短，已读范围以实际读到的原文为准。

## 开始

确认原文版本、可访问范围、交付目标与剧透要求。目录、附录、作者感言和缺失内容分别说明；小说正文全部纳入阅读范围。若只拿到残本，保留全文目标并说明缺失。

复用章节或分段索引。章号重号、倒叙或标题缺失时，使用文件内顺序与字符位置定位。分段应连续覆盖正文，长段可分几次读取；段大小服从工具实际能完整展示的容量。

整书分析采用下面的四步循环。要求保留初读体验时，预读只限当前获准范围，随阅读向前扩展，不能先看后文；局部核查只处理问题所需原文。短文本可缩短预读与波次。

## 核心循环

1. **稀疏预读，形成 `I0`。** 允许全书剧透时，跨全文看目录、各段标题和少量开头，必要时加少量中尾锚点。勾勒暂定结构、主要人物、时间层与冲突，分清看见、推测和未知，注明抽样偏差。成本应明显小于读全文；预读范围只记为“仅预览”。
2. **提出可检验的预测。** 从 `I0` 选少量值得追踪的结构、人物关系或规则猜测，记下依据、可能的替代解释，以及什么后文会支持或推翻它。可以大胆猜测，缺乏线索处保留未知；预测只指导注意力，剩余正文仍全部要读。
3. **按波完整精读，更新 `I1、I2…`。** 按叙述顺序读相邻若干段，一波可从 2–4 段起步，随容量与情节调整。实际读到波内全部正文，留意预测的支持、反例、意外和当前问题之外的重要内容。每波结束检视整体印象，简记推翻、缩小或新增的判断及原文位置；无实质变化时可记判断暂时保留。同步改动受影响的笔记或整理草稿。
4. **触发式反刍。** 身份揭示、规则矛盾、人物态度逆转、重复意象或新问题改变旧场景的理解时，定位旧段并重读原文及上下文，比较原先判断与当前证据。修订解释、保留竞争解释或注明仍未知，再带着修订继续下一波。回读范围以当前问题为限。

波次精读要求正文读全并理解关键联系；笔记与分析深度可以不同。平淡段可只记覆盖，重要变化多留几句，不要求逐章制卡、预测配额、固定波数或反复重写全书摘要。`I0、I1…` 可以保存在同一份简记中，只留当前印象与有意义的修订。

## 阅读边界

- 每次实际读取连续正文，确认输出没有截断或省略。遇到上限就缩小范围，从最后确认读到的位置续读；检索、抽样、脚本提取与摘要不能补出未读部分。
- 分清原文事实、人物说法、自己的解释与预测。前文猜测可以撤销，不能为保住 `I0` 将所有细节解释成伏笔；后文已明说的内容也不能回填为早先的预测。
- 涉及反转、倒叙、秘密或能力获得时，分清事件发生、文本披露、角色得知与读者在当时所知，保留当时的知识范围。
- 反刍需要实际回到旧原文。只连接两份摘要属于解释推演，不能记作已经回读。

具体预读、预测修订、波次与截断处理见 [阅读细则](references/protocol.md)。

## 与 durable-task 配合

同时使用 durable-task 时，由它管理恢复入口，本 skill 提供阅读状态。复用一份 `work/state.md` 或已有 `READING-STATE.md`，不要再维护一套相同进度。

入口保留：原文版本与索引、连续已读范围和缺口、部分段的精确断点、当前波与整体印象 `I_k`、仍待验证的预测和重要修订、关键笔记与待回读位置、下一步。可采用 [简短模板](templates/READING-STATE.md)，已有记录能续读即可。

恢复时先核对原文与索引，取回当前整体印象、预测与必要原文锚点，再从最早未覆盖处继续；沿用已有 `I_k`，不重新从头做预读。已核实的阅读记录可沿用；仅有“已完成”标签或章节标题时，需要确认实际范围。旧记录称“精读”的段保留原口径，不能因改名就补出阅读覆盖。版本变化只复核受影响的范围。

独立使用本 skill 时也保留同样的最小续读信息。单代理按上述循环推进即可；用户要求或已授权并行时，再读 [并行阅读](references/parallel-reading.md)。

## 阅读完成

对照索引确认正文从开头到结尾连续覆盖，补齐所有部分段与缺口，读到最后一段正文后再称“全文读完”。完整通读允许分析深度不同，不要求每句都形成解释。

全文目标未达到时，交付当前成果与准确断点，继续保留未读范围。交付详略可以缩减，全文阅读目标的变更由用户决定。阅读完成后按用户所需整理；做世界书时继续使用 novel-worldbook。
