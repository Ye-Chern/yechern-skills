# 渐进式阅读

整书阅读沿着“稀疏预读 → 预测 → 波次精读 → 反刍”推进：先形成可撤销的整体印象，再以完整阅读检验它，遇到新证据时回到旧原文修订。正文最终要连续覆盖到结尾；笔记详略随内容变化。通用边界见 [NOTICE](NOTICE.md)，少见情形与恢复方法见 [HELP](HELP.md)。

## 开始

确认原文版本、可访问范围、交付目标与剧透要求。复用章节或分段索引；没有索引时，可用 [分段脚本](scripts/segment_text.py) 处理 UTF-8 纯文本。新建一份简短阅读状态，或沿用已有恢复入口。

要求保留初读体验时，只在当前获准范围内预读，并随阅读向前扩展。允许全书剧透时可先稀疏查看全文。局部问题只核查相关原文，短文本可缩短预读与波次。

## 阅读循环

1. **稀疏预读，形成 `I0`。** 允许全书剧透时，跨全文看目录、段落标题和少量开头，必要时补少量中尾锚点。概括暂定结构、主要人物与关系、时间层或冲突，分清所见、推测与未知，并注明样本偏差。预读明显少于全文；样本之间仍是未读正文。
2. **提出可检验的预测。** 从 `I0` 中挑出值得追踪的结构、人物关系或规则猜测，记下原文依据、替代解释，以及什么内容会支持或推翻它。没有线索时保留未知。预测帮助留意后文，不替代阅读。
3. **按波完整精读，更新 `I1、I2…`。** 按叙述顺序读相邻若干段，一波可从 2–4 段起步，再按文本和工具容量调整。读完波内全部正文，记录预测的支持、反例、意外和当前问题之外的重要内容。每波对照上一版整体印象，简记保留、修正或新增的判断及原文位置；无实质变化时可记暂时保留。同步修改受影响的笔记或草稿。
4. **触发式反刍。** 身份揭示、规则矛盾、人物态度逆转、重复意象或新问题改变旧场景的理解时，定位并重读旧原文及上下文，比较先前判断和当前证据。修订解释、保留竞争解释或注明未知，再继续下一波。

不要求逐章制卡、预测配额、固定波数或每波强行回读。平淡段可以只记覆盖，重要变化多留几句。`I0、I1…` 可简记在一起，只保留当前印象与有意义的修订。

分清原文事实、角色说法、自己的解释和预测；后文揭示不能回填成早先已知。事件发生、文本披露和角色得知的先后在影响理解时分别记录。每次读取确认正文实际可见且连续；输出截断时按 [HELP](HELP.md#读取被截断) 续读，只登记确认读到的范围。

## 保存与恢复

同时使用 durable-task 时，让它管理恢复入口，本 skill 提供阅读状态；复用 `work/state.md` 或已有 `READING-STATE.md`，不要重复维护进度。可采用[简短模板](templates/READING-STATE.md)。入口至少能看出原文版本与索引、连续已读范围和缺口、部分段断点、当前整体印象、待验证预测、关键笔记或待回读位置，以及下一步。

恢复时核对原文与索引，取回现行印象、预测和必要锚点，从最早未覆盖处继续，不重做全书预读。已核实的阅读记录可沿用；仅有“已完成”标签或章节标题时，先确认实际覆盖。版本变化时复核受影响范围。

独立使用时也保存同样的最小续读信息。单代理按本页循环推进；用户要求或已授权并行时，参阅[并行阅读](references/parallel-reading.md)。预读、预测修订、波次记录与连续覆盖的操作细节见[阅读细则](references/protocol.md)。

## 完成

对照索引确认正文从开头到结尾连续覆盖，补齐部分段与缺口。读到最后一段正文后才记录“全文读完”；全文阅读允许分析深度不同。未完成时交付当前成果与准确断点，并保留全文目标。阅读完成后再按用户所需整理；制作世界书时使用 novel-worldbook。
