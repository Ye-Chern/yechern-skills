# 渐进式阅读

沿小说的叙述顺序读完正文，边读边修正理解。阅读详略与笔记多少可以调整，已读范围以实际读到的原文为准。

## 开始

确认原文版本、可访问范围、交付目标与剧透要求。目录、附录、作者感言和缺失内容分别说明；小说正文全部纳入阅读范围。若只拿到残本，保留全文目标并说明缺失。

复用章节或分段索引。章号重号、倒叙或标题缺失时，使用文件内顺序与字符位置定位。分段应连续覆盖正文，长段可分几次读取；段大小服从工具实际能完整展示的容量。

默认直接顺序阅读。允许全书剧透、且结构预览有助于理解时，可先少量看目录与节选，形成暂定印象；预读只记为“仅预览”。无剧透阅读从当前进度向前推进。

## 阅读与理解

- 每次实际读取一段连续正文，确认输出没有截断或省略。检索、抽样、脚本提取和摘要不能代替中间未读的文字。遇到输出上限就缩小范围，从最后确认读到的位置续读。
- 记录后续整理需要的事件、人物变化、设定与原文位置。平淡段可以只记覆盖；重要转折多留几句。按需要合并笔记，允许直接写入整理草稿。
- 对当前理解保留修订余地，也留意当前问题之外的重要内容。原文事实、人物说法、自己的解释与猜测分清；新内容与旧判断冲突时，改动受影响的笔记或草稿。没有线索时无需提出预测。
- 涉及反转、倒叙、秘密或能力获得时，分清事件发生、文本披露与角色得知的位置；保留当时的知识范围。
- 身份揭示、规则冲突或关键因果需要核实时，回到相关原文及上下文，再修订理解。回读范围以解决当前问题为限。

读完一段有意义的内容就更新覆盖与下一位置，继续读后文。笔记的细度由续读和交付需要决定，不要求每章制卡、逐句分析、固定波数或逐轮重写全书总结。需要具体分段与截断处理时读 [阅读细则](references/protocol.md)。

## 与 durable-task 配合

同时使用 durable-task 时，由它管理恢复入口，本 skill 提供阅读状态。复用一份 `work/state.md` 或已有 `READING-STATE.md`，不要再维护一套相同进度。

入口保留：原文版本与索引、连续已读范围和缺口、部分段的精确断点、关键笔记位置、仍影响理解的问题、下一步。可采用 [简短模板](templates/READING-STATE.md)，已有记录能续读即可。

恢复时先核对原文与索引，再从最早未覆盖处继续。已核实的阅读记录可沿用；仅有“已完成”标签或章节标题时，需要确认实际范围。旧记录称“精读”的段保留原口径，不能因改名就补出阅读覆盖。版本变化只复核受影响的范围。

独立使用本 skill 时也保留同样的最小续读信息。单代理顺序阅读足够；用户要求或已授权并行时，再读 [并行阅读](references/parallel-reading.md)。

## 阅读完成

对照索引确认正文从开头到结尾连续覆盖，补齐所有部分段与缺口，读到最后一段正文后再称“全文读完”。完整通读允许分析深度不同，不要求每句都形成解释。

全文目标未达到时，交付当前成果与准确断点，继续保留未读范围。交付详略可以缩减，全文阅读目标的变更由用户决定。阅读完成后按用户所需整理；做世界书时继续使用 novel-worldbook。
