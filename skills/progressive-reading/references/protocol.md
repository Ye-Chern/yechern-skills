# 渐进式阅读细则

## 原文与位置

保留可回查的原文。转换 PDF、EPUB 或其他格式时，确认正文顺序、首尾和明显缺页；转换失败的部分留作缺口。章名或目录不能证明正文齐全。

有可靠章节索引就沿用。需要切分 UTF-8 纯文本时，可在本 skill 目录运行：

```text
python scripts/segment_text.py novel.txt --out reading-input --size 8000
```

路径按环境调整，输出目录须为空。脚本保留原文换行，偏移采用 Python Unicode 字符下标、左闭右开 `[start, end)`；其他工具的字节或 UTF-16 下标须先换算。原稿转码或改换行后重新确认定位。

`manifest.json` 说明文本版本和连续分段，片段拼接可还原输入。它的 `reading_status: unread` 是生成时的初始值；实际进度统一写在项目入口或它所指的覆盖文件中。脚本运行成功只说明完成了分段。

整体分析用 `scout.txt` 做稀疏预读；保留初读体验时，加 `--no-scout`，避免生成跨全书的标题与开头预览。分段脚本是可选工具，已有索引可直接使用。

## 稀疏预读与预测：I0

将样本分散到全文各段，先看目录、标题和少量开头。例如每段 150–500 字；开头容易误导时，补少量中部或尾部锚点。篇幅很长时可分批查看样本，最后合成一份简短 `I0`；看到的是样本，样本之间的正文仍未读。

`I0` 保留暂定结构、重要人物与关系、时间层或主要冲突，以及少量值得检验的预测。用短句区分原文已见、自己的推测和未知。无剧透模式只在当前获准范围内做这一步。

预测可这样简记：

```text
H1：可能发生什么或结构如何；依据：已见的原文位置。
替代解释：同一线索还可能说明什么。
待检验：什么新内容会支持、缩小或推翻它。
```

不必每段提出预测或填写所有栏目。没有依据处留未知；已在预读样本中看见的后文揭示，应记为所见，不能算提前猜中。预测指导下一波留意什么，不改变全文必须覆盖的范围。

## 波次精读与整体修订：I1、I2…

一波是能连起来理解的相邻几段，可从 2–4 段起步；工具单次读取范围可以更小。按叙述顺序读完这些段，记关键事件、人物状态与知识/能力变化、必要的语言细节和来源位置。留意支持、抵触与预测之外的新线索。

每波结束对照上一版整体印象，保留当前结构和重要修订即可。例如：

```text
I2：H1 原以为发生了时间回拨；新段表明这里只是插叙，已修正。
依据：本波与旧场景的真实位置。
下一波：继续尚未读取的正文；回看旧场景的时间交代。
```

以上只是写法示例，实际记录须使用小说中的真实位置。某波没有实质修订时，记下原判断暂时保留及仍待验证的问题即可。保留仍影响后续理解的推翻原因，不重写整本摘要，也不为更新版本硬造变化。

后文出现前先记下的预测，才有前后检验的意义。同一波内已经得知的结果，属于当波理解；不为普通阅读统计猜中率。新内容推翻旧判断时同步改现行笔记和世界书条目，防止旧说法继续流入产物。

## 实际读取

选择工具能完整显示的小范围，读取后确认正文和结束位置。输出有省略号、截断提示或中间缺失时，只登记能确认读过的部分，再读缺口。一次工具调用返回了长文件，也须确认内容确实完整可见。

例如某段为 `[8000, 16000)`，本次完整看到 `[8000, 11200)`，就记录“部分通读，下一位置 11200”。下一次从 11200 继续；边界不清时适当重叠。只有本段各部分都读到，才能记为“已通读”。

状态可用“未读 / 仅预览 / 部分通读 / 已通读”。连续范围可合并，如 `S001–S008 已通读；S009 已读至字符 67500`，不必逐段建文件。若跳读过，另列缺口，下一位置取最早未读处。无法确定旧覆盖时，核查相关记录；必要时从最近可靠断点补读。

检查全读时，对照连续范围确认没有遗漏。需要百分比时，以已实际阅读区间的并集除以正文总范围，重复回读只计一次；章长不等时不把章数比例当字数比例。字符、区间、标题数与笔记文件数都不能自行证明模型读懂了文本。

## 笔记与修订

笔记回答当前用途需要的问题：发生了什么、什么变了、以后去哪查。主要人物与规则变化多留位置，重复描写可少记；不按字数配额填栏目。来源常用“章节顺序 + 章题 + 段落或短语”，精确偏移已有则直接引用。

跨上下文保留两类信息：已核实的事实与结论；可重新思考的原文锚点、未解疑问、预测及反例。复用同一入口和笔记，不只对上一份摘要反复压缩。阅读预测通常留在工作笔记中，成品按查阅需要取舍。

## 反刍的实际动作

新揭示、身份变化、规则矛盾、人物态度逆转、意象重现或用户问题，使旧场景值得重新理解时：定位旧段 → 读取原文及相邻上下文 → 比较旧判断与新证据 → 修订或保留歧义。记一句改变原因及位置，带入下一波。

不必每波强行回读。只看旧摘要时注明尚未回到原文；取不到相关原文时保留待回读项。原文没有交代的规则与关系标为未说明，不能把全部前文细节事后归为伏笔。
