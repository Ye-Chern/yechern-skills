# 阅读细则

## 原文与分段

有可靠章节索引就沿用。纯文本可运行：

```text
python scripts/segment_text.py novel.txt --out reading-input --size 8000
```

输出目录须为空。脚本保留原文换行并生成 `manifest.json`；默认还生成 `scout.txt`，用 `--no-scout` 可跳过全文预览。`manifest.json` 中 `reading_status: unread` 是生成时的初始状态，实际进度写入阅读状态入口。脚本运行成功只表示分段完成。

`manifest.json` 记录原文件名、SHA-256、字符数和连续分段；片段拼接应还原输入。偏移是 Python Unicode 字符下标，左闭右开 `[start, end)`。章节标题识别只是启发式索引，不能代替检查正文首尾和完整性。

## 稀疏预读与预测

将样本分散到各段，先看目录、标题和少量开头；每段可取约 150–500 字，开头容易误导时补少量中部或尾部锚点。篇幅很长可分批查看，再汇成简短 `I0`。不必逐段采样，样本之间的正文留待精读。

预测可用短记：

```text
H1：可能发生什么或结构如何；依据：已见原文位置。
替代解释：同一线索还可能说明什么。
待检验：什么新内容会支持、缩小或推翻它。
```

预测数量按线索与用途决定。后文揭示若已在预读样本中出现，应记录为所见，不能算提前预测成功。

## 波次记录

按文本顺序读完一组相邻段落。若工具容量小于整段，分几次读并续接到该段末尾，再结束这一波。记录能支持后续理解的事件、人物状态或知识变化，以及原文位置。示例：

```text
I2：H1 原以为发生时间回拨；新段表明这里只是插叙，已修正。
依据：本波与旧场景的时间交代。
下一步：继续最早未读正文；回看旧场景的时间线索。
```

真实笔记应使用作品中的实际位置。若判断暂时保留，记下仍待验证的问题即可；保留会影响后续理解的修订原因，不必反复重写全书摘要。

## 阅读范围记录

可用“未读 / 仅预览 / 部分通读 / 已通读”。例如某段范围为 `[8000, 16000)`，只看到 `[8000, 11200)` 时，记下已读到 11200，并从此处续读。连续范围可合并记录，如 `S001–S008 已通读；S009 已读至字符 67500`；跳读处另列缺口，下一步从最早缺口开始。

如需估算进度，以实际阅读区间并集长度除以正文总长度；重复回读只计一次，章数比例不能代表字数比例。区间覆盖说明读过哪些文字，不单独证明理解程度。

## 笔记

笔记服务于后续查阅：发生了什么、什么改变、原文在哪里。常用出处为“章节顺序 + 章题 + 段落或短语”；已有精确偏移时直接引用。跨上下文保留核实过的事实与结论，也保留可以重新思考的原文锚点、疑问、预测和反例。复用同一入口与笔记，不要只对上一版摘要继续压缩。
