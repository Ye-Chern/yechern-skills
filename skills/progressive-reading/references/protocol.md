# 分段、覆盖与回读

## 原文与位置

保留可回查的原文。转换 PDF、EPUB 或其他格式时，确认正文顺序、首尾和明显缺页；转换失败的部分留作缺口。章名或目录不能证明正文齐全。

有可靠章节索引就沿用。需要切分 UTF-8 纯文本时，可在本 skill 目录运行：

```text
python scripts/segment_text.py novel.txt --out reading-input --size 8000 --no-scout
```

路径按环境调整，输出目录须为空。脚本保留原文换行，偏移采用 Python Unicode 字符下标、左闭右开 `[start, end)`；其他工具的字节或 UTF-16 下标须先换算。原稿转码或改换行后重新确认定位。

`manifest.json` 说明文本版本和连续分段，片段拼接可还原输入。它的 `reading_status: unread` 是生成时的初始值；实际进度统一写在项目入口或它所指的覆盖文件中。脚本运行成功只说明完成了分段。

允许后文预览时，可省略 `--no-scout`，用 `scout.txt` 看少量标题和开头。通常一份简短整体印象就够；只有值得追踪的猜测才记依据与待验证处。

## 实际读取

选择工具能完整显示的小范围，读取后确认正文和结束位置。输出有省略号、截断提示或中间缺失时，只登记能确认读过的部分，再读缺口。一次工具调用返回了长文件，也须确认内容确实完整可见。

例如某段为 `[8000, 16000)`，本次完整看到 `[8000, 11200)`，就记录“部分通读，下一位置 11200”。下一次从 11200 继续；边界不清时适当重叠。只有本段各部分都读到，才能记为“已通读”。

状态可用“未读 / 仅预览 / 部分通读 / 已通读”。连续范围可合并，如 `S001–S008 已通读；S009 已读至字符 67500`，不必逐段建文件。若跳读过，另列缺口，下一位置取最早未读处。无法确定旧覆盖时，核查相关记录；必要时从最近可靠断点补读。

检查全读时，对照连续范围确认没有遗漏。需要百分比时，以已实际阅读区间的并集除以正文总范围，重复回读只计一次；章长不等时不把章数比例当字数比例。字符、区间、标题数与笔记文件数都不能自行证明模型读懂了文本。

## 笔记与修订

笔记回答当前用途需要的问题：发生了什么、什么变了、以后去哪查。主要人物与规则变化多留位置，重复描写可少记；不按字数配额填栏目。来源常用“章节顺序 + 章题 + 段落或短语”，精确偏移已有则直接引用。

后文推翻旧判断时，改现行笔记或世界书条目，必要时用一句话保留改动原因。只保留仍有帮助的旧解释。后文已经说明的事实不能冒充初读时猜中的结果；阅读预测通常留在工作笔记中。

回读先查当前疑问需要的旧场景和相邻上下文。仍有多种合理解释就保留歧义；原文没有交代的规则与关系标为未说明。
